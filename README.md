# Simple: IT-офис по подписке

Сайт Simple: сайты, автоматизация, интеграции, боты и AI для компании за 60 000 ₽ в месяц.
Статический сайт без сборки: HTML, CSS и JavaScript без фреймворков.

Живая версия: https://volgin.site/simple/

## Страницы

- `index.html`: главная
- `works.html`: все работы
- `brief.html`: бриф «Обсудить задачу»
- `consent.html`: согласие на обработку персональных данных (отдельный документ, на него ведёт отметка в брифе)

## Запуск у себя

Подойдёт любой статический сервер из папки сайта, например:

```bash
npx http-server . -p 5195
```

## Слабые компьютеры и телефоны

Сайт сам выбирает один из трёх режимов: полный, облегчённый (`lite`) и спокойный (`calm`, фоны стоят,
пиксельного фона нет). Выбор идёт по видеокарте, если браузер её называет, и по замерам кадров
при загрузке и прокрутке; код в `common.js`. Посмотреть режим вручную: `?quality=full`, `?quality=lite`,
`?quality=calm`, вернуть автоматический выбор: `?quality=auto`.

## Заявки с брифа

Бриф отправляет заявку на `tz.simplemind.ru/api/brief`. Приёмник принимает запросы только со своего домена,
поэтому рабочая отправка возможна, когда страница открыта на tz.simplemind.ru. На других адресах форма
покажет ошибку отправки и запасной путь: ответы одним текстом можно скопировать и прислать в Telegram или на почту,
а сами ответы останутся сохранены в браузере.

## Данные посетителей

Сайт не ставит куки и не подключает аналитику. Шрифт Onest лежит в `assets/fonts` (SIL OFL), сторонних запросов
страницы не делают. Политика оператора: https://simplemind.ru/privacy, согласие: `consent.html`.
