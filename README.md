# Simple: автоматизация, которая работает сама

Сайт Simple: автоматизируем процессы компании так, чтобы дальше они работали сами, плюс сайты, боты, интеграции и AI. Работаем на задачу: оцениваем сложность и называем цену до начала работы.
Статический сайт без сборки: HTML, CSS и JavaScript без фреймворков.

Живая версия: https://simplemind.ru/ (сервер Simple), копия: https://volgin.site/simple/

## Страницы

- `index.html`: главная
- `works.html`: все работы
- `brief.html`: бриф «Обсудить задачу»
- `consent.html`: согласие на обработку персональных данных (отдельный документ, на него ведёт отметка в брифе)
- `privacy.html`: политика обработки персональных данных оператора (на simplemind.ru отдаётся и по адресу /privacy)

## Запуск у себя

Подойдёт любой статический сервер из папки сайта, например:

```bash
npx http-server . -p 5195
```

## Выкладка на simplemind.ru

Файлы лежат на сервере Simple в `/srv/simple-web/releases/<дата-коммит>/`, действующая выкладка — ссылка
`/srv/simple-web/current`. Новая выкладка: распаковать архив коммита (`git archive`) в новую папку releases
и переставить ссылку current; откат — вернуть ссылку на прошлую папку. nginx отдаёт файлы как статику,
`/privacy` открывает `privacy.html`, а `/api/brief`, `/logclub` и `/api/logclub` уходят в службу брифа.

## Слабые компьютеры и телефоны

Сайт сам выбирает один из трёх режимов: полный, облегчённый (`lite`) и спокойный (`calm`, фоны стоят,
пиксельного фона нет). Выбор идёт по видеокарте, если браузер её называет, и по замерам кадров
при загрузке и прокрутке; код в `common.js`. Посмотреть режим вручную: `?quality=full`, `?quality=lite`,
`?quality=calm`, вернуть автоматический выбор: `?quality=auto`.

## Заявки с брифа

Бриф отправляет заявку в службу брифа на сервере Simple. На simplemind.ru и tz.simplemind.ru она доступна по адресу
`/api/brief` того же домена; со сторонних адресов (копия на volgin.site) запрос уходит на `tz.simplemind.ru/api/brief`,
заявка сохраняется, но браузер не даёт прочитать ответ. Если отправка не удалась, бриф показывает запасной путь:
ответы одним текстом можно скопировать и прислать в Telegram или на почту, а сами ответы остаются сохранены в браузере.

## Поиск

Название для поисковиков «Simple Mind» (так набирают адрес simplemind.ru): оно в заголовках страниц, в подвале
и в разметке schema.org на главной (WebSite и Organization, с вариантами SimpleMind, Simple, Симпл Майнд).
`robots.txt` и `sitemap.xml` лежат в корне; в карте адреса как в canonical страниц. Превью ссылки в мессенджерах:
`assets/og.png` (1200×630), логотип для поисковиков и иконка на телефоне: `assets/logo-512.png`.

## Данные посетителей

Сайт не ставит куки и не подключает аналитику. Шрифт Onest лежит в `assets/fonts` (SIL OFL), сторонних запросов
страницы не делают. Политика оператора: `privacy.html`, согласие: `consent.html`.
